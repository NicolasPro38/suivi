# Suivi

Application web de suivi géolocalisé d'objets/véhicules.

## Stack
- Backend : Python / Flask
- Base de données : PostgreSQL / PostGIS
- Frontend : HTML / CSS / JS / Leaflet.js

## Lancer en local
```bash
cd suivi
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
flask run
```
